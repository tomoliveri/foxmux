# Security policy

foxmux runs a shell as you, so security bugs matter. Please report them
privately through
[GitHub's private vulnerability reporting](https://github.com/tomoliveri/foxmux/security/advisories/new)
rather than in a public issue.

Only the latest release is supported; fixes ship as new releases, which
installed copies pick up automatically.

See the _Security_ section of the [README](README.md#security) for the design.
